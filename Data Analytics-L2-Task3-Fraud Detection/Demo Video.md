## Video Contents

The demo video presents:

- Project title and internship information.
- Dataset loading and verification using the Kaggle Credit Card Fraud Detection dataset.
- Initial inspection of transaction records, features, data types, missing values, and duplicates.
- Class-imbalance analysis showing 492 fraudulent transactions out of 284,807 transactions.
- Exploratory data analysis of transaction amounts and elapsed transaction time.
- Feature engineering using `time_hours` and `log_amount`.
- Stratified train/test splitting to preserve fraud cases in both datasets.
- Data-leakage prevention using an imbalanced-learn Pipeline.
- SMOTE oversampling applied only to the training data.
- Logistic Regression training and evaluation.
- Random Forest training using balanced class weights.
- Model evaluation using Precision, Recall, F1-score, ROC-AUC, and PR-AUC.
- Confusion matrix, ROC curve, and Precision-Recall curve analysis.
- Decision-threshold optimization and the Precision-Recall trade-off.
- Feature coefficient analysis and Random Forest feature importance.
- Final model comparison and fraud-detection recommendations.
- Scalability discussion for processing one million transactions per hour.
